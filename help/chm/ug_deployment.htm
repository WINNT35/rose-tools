Deployment

Rose Tools v0.2 does not include an installer. Files must be copied manually to the correct locations. An installer is planned for v0.3.

Directory Layout

Create the following directory structure under Program Files. The directory name and layout must be exact, as vmrosd.exe expects plugins at a specific path by default.

C:\Program Files\VMware\Rose Tools\
    vmrosd.exe
    tools.conf          (optional, create if needed)
    plugins\
        vmsvc\
            guestInfo.dll
            timeSync.dll
            resolutionSet.dll

Copying the Files

Copy the VMware folder from the Rose Tools release into C:\Program Files\. The resulting path should be C:\Program Files\VMware\Rose Tools\. The plugins folder must also be present with the DLLs in place before vmrosd.exe is started, otherwise the plugin manager will find nothing to load.

First Run

Before registering Rose Tools as a service, run vmrosd.exe directly from the command line to confirm everything is working. A successful startup looks like this:

v0.2 (interactive mode)
vmrosd: no config file found, using defaults.
pluginMgr: loading plugins from: C:\Program Files\VMware\Rose Tools\plugins\vmsvc
pluginMgr: plugin 'guestInfo' loaded.
pluginMgr: plugin 'timeSync' loaded.
resolutionSet: Disabled. See documentation to learn more.
vmrosd: 2 plugin(s) loaded, entering main loop.

--- rose-tools v0.2 self-test ---
  VMware detected:          PASS
  RPC channel opened:       PASS
  Version sent to VMX:      PASS
  TCLO reset received:      PASS
  Capabilities registered:  PASS
  Plugin(s) loaded:         PASS
  Heartbeat loop running:   PASS
---------------------------------
Congratulations, v0.2 works as expected.

The banner v0.2 (interactive mode) confirms that vmrosd.exe was launched directly rather than by the Windows Service Control Manager. Once you have confirmed the self-test passes, proceed to Service Registration to install Rose Tools as an automatic service.

VMware Tools Conflict

If VMware Tools is already installed on the guest, vmrosd.exe will detect it and refuse to start. Remove VMware Tools before deploying Rose Tools. If you need to run both, see the Configuration File page for the override option.
