About Rose Tools

Background

Rose Tools began as an effort to bring VMware guest services to the ReactOS community. Porting individual tools without a shared core proved unstable, so the decision was made to port open-vm-tools as a whole; providing a solid foundation that future components can build upon. The goal is to make ReactOS significantly more usable when running inside VMware virtual machines.

What Rose Tools Does

Rose Tools v0.2 builds on the v0.1 core with a significantly expanded feature set. vmrosd.exe now runs as a Windows service and loads plugins dynamically from a configurable directory. Two new plugins are included: timeSync, which keeps the guest clock synchronized with the VMware host, and resolutionSet, which allows the VMware window to resize the guest display. checkvm.exe continues to provide standalone VM detection. Rose Tools has been tested on Windows XP and ReactOS. See the User Guide for deployment instructions.

Relationship to open-vm-tools

Rose Tools is derived from open-vm-tools. The guest protocol layer is preserved as closely as possible, modified only where necessary for Windows NT compatibility, with no dependency on GLib. The core libraries are largely derived from upstream. The outer ring is primarily original Win32 code, though several files are closely based on upstream open-vm-tools and carry dual attribution accordingly. See the License page for the full breakdown.
