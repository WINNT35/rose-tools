Configuration File

Rose Tools reads an optional configuration file, tools.conf, located at C:\Program Files\VMware\Rose Tools\tools.conf. If the file is not found, all defaults apply and a message is printed at startup. The configuration path is hardcoded in v0.2; a registry-based path and --config flag are planned for v0.3.

Format

tools.conf uses a simple INI format. Sections are declared with a name in square brackets. Keys and values are separated by an equals sign. Lines beginning with # or ; are comments and are ignored. Whitespace around keys and values is stripped. Section and key names are case sensitive and must be written exactly as shown. An example:

# This is a comment
[vmtools]
ignore_vmware_tools=true

[resolutionset]
enable=true

Supported Keys

[vmtools]

ignore_vmware_tools (true/false, default: false) — By default, Rose Tools will refuse to start if a VMware Tools installation is detected. This is because both Rose Tools and VMware Tools use the same VMware RPC channel, and if VMware Tools is already running, vmrosd will almost certainly fail to initialize. Detection works by checking whether C:\Program Files\VMware\VMware Tools exists. This check will be made more sophisticated in a future release. Set this to true to bypass it, but expect vmrosd to fail unless VMware Tools is not actively running.

plugin_dir (path, default: C:\Program Files\VMware\Rose Tools\plugins\vmsvc) — Overrides the directory that the plugin manager scans for DLLs. Useful if you want to keep plugins in a non-standard location.

[resolutionset]

enable (true/false, default: false) — Enables the resolutionSet plugin, which allows the VMware window to resize the guest display. Disabled by default. Note that arbitrary resolutions require a native rose-tools display driver, which is planned for a future release. See the v0.2 changelog for details.

[timesync]

disable (true/false, default: false) — Disables all time synchronization.

disablePeriodic (true/false, default: false) — Disables periodic time synchronization only. The clock will still be corrected on resume from suspend.

Note: guestInfo does not currently have a configuration key and cannot be disabled. A future release will make all plugins individually configurable; in the meantime, removing guestInfo.dll from the plugins directory will prevent it from loading, but this is not recommended as Rose Tools depends on it for basic host communication.

Example File

[vmtools]
ignore_vmware_tools=false
plugin_dir=C:\Program Files\VMware\Rose Tools\plugins\vmsvc

[resolutionset]
enable=true

[timesync]
disable=false
disablePeriodic=false
