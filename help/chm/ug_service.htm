Service Registration

Rose Tools can run as a Windows service that starts automatically with Windows. The same vmrosd.exe binary handles both interactive and service mode. Before registering as a service, confirm that Rose Tools works correctly in interactive mode first. See Deployment for details.

Registering the Service

Open a command prompt with sufficient permissions and run the following command:

sc create rose-tools binPath= "C:\Program Files\VMware\Rose Tools\vmrosd.exe" DisplayName= "Rose Tools" start= auto

Note that sc requires a space between each parameter name and its value (e.g. binPath= followed by a space, then the path). Omitting these spaces is a common source of errors.

Starting and Stopping the Service

To start the service immediately without rebooting:

sc start rose-tools

To stop the service:

sc stop rose-tools

Removing the Service

To unregister Rose Tools from the SCM, stop the service first and then delete it:

sc stop rose-tools
sc delete rose-tools

Verifying the Service is Running

To check the current status of the service:

sc query rose-tools

A running service will show STATE: 4 RUNNING. If the service fails to start, run vmrosd.exe interactively first to check for errors. The most common cause is a VMware Tools conflict; see the Configuration File page for details.
