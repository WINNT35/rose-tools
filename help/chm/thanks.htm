Thanks & References

open-vm-tools

Rose Tools' core is derived from open-vm-tools, the open source implementation of VMware Tools developed by VMware. open-vm-tools was an invaluable reference and foundation for the guest protocol implementation and core libraries in Rose Tools.

open-vm-tools is available at https://github.com/vmware/open-vm-tools.

OSDev Wiki

The OSDev Wiki article on VMware Tools was a useful reference for understanding the VMware guest protocol, particularly for display resolution handling.

Available at https://wiki.osdev.org/VMware_tools.
